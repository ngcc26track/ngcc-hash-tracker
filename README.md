# NGCC Hash Round 1 Tracker

Unofficial, bilingual (中文 / English) tracker for the 35 Round 1 candidates of the NGCC call for
cryptographic hash algorithms: public forum findings, submitter responses, revisions, submission
documents and a unified software benchmark.

Site: https://ngcc26track.github.io/ngcc-hash-tracker/

- Sources: the CryptHash public comment forum (list.niccs.org.cn) and the official submission packages
  (niccs.org.cn). The forum posts and official materials are authoritative.
- Highlights, one-line summaries and the maintainers' verification reflect only the views of the site
  maintainers and may contain errors. Corrections are welcome in the relevant forum thread.
- `docs/submission/` holds copies of PDFs from the official submission packages for convenient viewing.

本站为非官方整理，汇总 NGCC 密码杂凑算法第一轮 35 个候选在 CryptHash 公开论坛上的评论、提交方回应、
版本更新与提交文档。算法亮点、一句话总结与维护方核验仅代表网站维护方观点；内容以论坛原帖与官方材料为准。
